# 咩咩手机界面 - MVU 变量体系详解

## 📋 概览

咩咩手机界面通过 **MVU 变量框架** 来管理手机内部的所有数据。整个手机数据以树形结构组织，根节点是 `stat_data.手机数据`，包含时间、用户信息和联系人等多个维度的数据。

---

## 🏗️ 核心数据结构

```
stat_data（消息楼层变量）
└── 手机数据
    ├── 当前时间
    ├── 用户
    │   ├── 昵称
    │   ├── 头像描述
    │   └── 空间动态 (动态列表)
    └── 联系人
        ├── 甘雨
        │   ├── 昵称
        │   ├── 签名
        │   ├── 头像
        │   ├── 头像描述
        │   ├── 聊天记录 (消息对象集合)
        │   └── 空间动态 (动态列表)
        ├── 神里绫华
        │   └── ... (同上)
        ├── 八重神子
        │   └── ... (同上)
        └── Nova
            └── ... (同上)
```

---

## 📱 变量设计详解

### 1️⃣ **当前时间** `手机数据.当前时间`

| 属性 | 详情 |
|------|------|
| **类型** | String |
| **格式** | `"YYYY-MM-DD HH:MM:SS"` 例如 `"2025-01-23 18:00:00"` |
| **含义** | 手机界面显示的当前时间，推进故事情节的时间标记 |
| **对应功能** | 时间条 / 系统时间显示 |
| **更新触发** | 每次对话互动后、新的一天开始、重要事件发生 |
| **存储位置** | `stat_data.手机数据.当前时间` |

**更新示例：**
```
_.set('手机数据.当前时间', '2025-01-23 18:00:00', '2025-01-23 19:00:00');
```

---

### 2️⃣ **用户信息** `手机数据.用户`

#### 用户 - 昵称 `用户.昵称`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | 例如 `"咩咩"` |
| **含义** | 玩家角色在手机中的昵称 |
| **对应功能** | 用户资料显示 |
| **修改权限** | 🔒 运行时不可修改 |

#### 用户 - 头像描述 `用户.头像描述`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | 例如 `"一张阳光下的自拍照"` |
| **含义** | 用户头像的文本描述，用于生成或选择头像 |
| **对应功能** | 用户资料 - 头像显示 |
| **修改权限** | 🔒 运行时不可修改 |

#### 用户 - 空间动态 `用户.空间动态`
| 属性 | 详情 |
|------|------|
| **类型** | Array |
| **结构** | 数组，包含多个动态对象 |
| **含义** | 用户发布的所有动态记录 |
| **对应功能** | 用户资料 - 空间 / 朋友圈 |
| **修改规则** | 用户发布新动态时添加新元素 |

**动态对象结构：**
```typescript
{
  时间: "2025-01-23 18:00:00",      // 发布时间
  内容: "今天天气不错",              // 动态文本
  评论列表: [
    {
      ID: "{{user}}",                // 评论者ID，用户评论时用 {{user}}
      发言内容: "确实很不错！"
    },
    {
      ID: "甘雨",                    // 评论者ID，联系人评论用联系人名称
      发言内容: "同意！"
    }
  ]
}
```

---

### 3️⃣ **联系人集合** `手机数据.联系人`

联系人是**可扩展的对象集合**，每个联系人以其名称作为 KEY，包含该联系人的完整信息。

#### 联系人 - 昵称 `联系人.{联系人名}.昵称`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | 例如 `"清心花茶"` (甘雨), `"白鹭"` (神里绫华) |
| **含义** | 玩家对该联系人的称呼/昵称 |
| **对应功能** | 联系人列表显示 / 聊天窗口联系人名显示 |
| **修改规则** | 关系变化时可能更新，一般保持稳定 |

#### 联系人 - 签名 `联系人.{联系人名}.签名`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | 例如 `"工作再忙,也要注意休息哦"` |
| **含义** | 联系人的个性签名/状态描述 |
| **对应功能** | 联系人资料 - 个性签名显示 |
| **修改规则** | 联系人心情/状态重大变化时更新；定期更新以反映当前生活状态 |

#### 联系人 - 头像 `联系人.{联系人名}.头像`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | URL 或标识符，例如 `"https://pub-a36fa2b8a8044f89a3426fa759085b6c.r2.dev/立绘_甘雨.png"` |
| **含义** | 联系人头像的网络资源地址 |
| **对应功能** | 联系人列表 / 聊天窗口头像显示 |
| **修改权限** | 🔒 运行时不可修改 |

#### 联系人 - 头像描述 `联系人.{联系人名}.头像描述`
| 属性 | 详情 |
|------|------|
| **类型** | String |
| **取值** | 例如 `"一位温柔恬静、气质优雅的女性照片,穿着职业装"` |
| **含义** | 联系人头像的文本描述 |
| **对应功能** | 头像生成 / 备选显示 |
| **修改权限** | 🔒 运行时不可修改 |

#### 联系人 - 聊天记录 `联系人.{联系人名}.聊天记录`
| 属性 | 详情 |
|------|------|
| **类型** | Object (可扩展) |
| **KEY 格式** | 消息时间戳 `"2025-01-23 18:00:00"` |
| **含义** | 与该联系人的所有聊天消息记录 |
| **对应功能** | 聊天窗口显示 |
| **修改规则** | 每次对话时添加新的时间消息条目 |

**消息对象结构：**
```typescript
{
  is_user: true,                  // true=玩家消息，false=联系人消息
  message: "现在有时间聊聊吗？"    // 消息内容
}
```

**时间消息规则：**
- KEY 值必须是格式化时间字符串 `"YYYY-MM-DD HH:MM:SS"`
- 消息时间应略晚于当前剧情时间（手机数据.当前时间）
- 例如：当前时间为 `"2025-01-23 09:00:00"`，新消息时间应为 `"2025-01-23 09:01:00"` 或更晚

#### 联系人 - 空间动态 `联系人.{联系人名}.空间动态`
| 属性 | 详情 |
|------|------|
| **类型** | Array |
| **结构** | 与用户空间动态结构相同 |
| **含义** | 该联系人发布的所有动态记录 |
| **对应功能** | 联系人资料 - 空间 / 朋友圈 |
| **修改规则** | 联系人发布新动态时在数组中添加元素 |

## 🔄 变量更新规则速查表

| 变量 | 修改方式 | 触发条件 |
|------|--------|--------|
| 当前时间 | ✏️ 可修改 | 每次对话/互动后、新的一天、重要事件 |
| 用户昵称 | 🔒 不可修改 | - |
| 用户头像描述 | 🔒 不可修改 | - |
| 用户空间动态 | ➕ 添加元素 | 用户发布新动态 |
| 联系人昵称 | ✏️ 可修改 | 关系变化 |
| 联系人签名 | ✏️ 可修改 | 心情/状态变化、定期更新 |
| 联系人头像 | 🔒 不可修改 | - |
| 联系人头像描述 | 🔒 不可修改 | - |
| 聊天记录 | ➕ 添加条目 | 每次与该联系人对话 |
| 空间动态 | ➕ 添加元素 | 联系人发布新动态 |

## 💾 存储位置速查

所有变量都存储在 **消息楼层变量** 中：

```
getVariables({ type: 'message', message_id: {当前消息ID} })
└── stat_data.手机数据
```

在代码中访问时，通常使用：

```typescript
// 读取
const phoneData = Mvu.getMvuData({ type: 'message', message_id: 5 });
const currentTime = _.get(phoneData, 'stat_data.手机数据.当前时间');

// 修改（MVU 指令格式）
_.set('手机数据.当前时间', oldValue, newValue);
_.insert('手机数据.联系人.甘雨.聊天记录', '2025-01-23 18:00:00', {is_user: true, message: '...'});
_.insert('手机数据.联系人.甘雨.空间动态', {时间: '...', 内容: '...', 评论列表: []});
```

## 📊 变量维度分类

### 🕐 时间维度
- 当前时间 → 故事推进的时间线

### 👤 用户维度
- 用户昵称 → 玩家身份标识
- 用户头像描述 → 玩家外观
- 用户空间动态 → 玩家的分享/动态

### 👥 联系人维度（多个）
- 昵称 → 关系标签
- 签名 → 联系人状态
- 头像 → 联系人外观
- 聊天记录 → 与该联系人的互动历史
- 空间动态 → 联系人的分享/动态

## 🎯 常见操作示例

### 推进时间
```typescript
_.set('手机数据.当前时间', '2025-01-23 18:00:00', '2025-01-23 19:00:00');
```

### 添加新聊天消息
```typescript
_.insert('手机数据.联系人.甘雨.聊天记录', '2025-01-23 18:30:00', {
  is_user: true,
  message: '你在吗？'
});
```

### 联系人发布动态
```typescript
_.insert('手机数据.联系人.神里绫华.空间动态', {
  时间: '2025-01-23 17:30:00',
  内容: '今天的晨练很愉快',
  评论列表: [
    { ID: '{{user}}', 发言内容: '很赞！' }
  ]
});
```

### 更新联系人签名
```typescript
_.set('手机数据.联系人.甘雨.签名', '工作再忙,也要注意休息哦', '最近工作太忙了...');
```

### 添加新联系人
```typescript
// 先确保 "新联系人名" 这个 KEY 对应的联系人存在
_.insert('手机数据.联系人', '新联系人名', {
  昵称: '称呼',
  签名: '个性签名',
  头像: 'URL',
  头像描述: '描述',
  聊天记录: { '$meta': {...} },
  空间动态: ['$__META_EXTENSIBLE__$']
});
```

## 📝 笔记

- **可扩展性**：联系人集合支持动态添加新联系人，无需预定义
- **时间一致性**：消息时间必须晚于当前时间，保证时间线的逻辑完整性
- **不可变字段**：头像相关字段和用户身份字段在运行时固定，不可修改
- **MVU 框架**：所有数据更新通过 MVU 指令系统自动处理，AI 可在输出中使用指令语句
