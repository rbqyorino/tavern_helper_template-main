## 🚀 使用方法

### 基本使用

1. **在世界书中配置格式规范**
   - 告诉AI如何生成Phone格式的消息
   - 参考：MESSAGE_FORMAT.md

2. **AI生成的消息格式**
   ```
   Phone.Private('小李','小明','今天天气真好[emoji-开心]','18:30');
   Phone.Home('小王','今天去公园散步[image-公园]','14:20');
   ```

3. **脚本会自动**
   - 解析消息
   - 添加到手机界面
   - 保存数据
   - 显示在UI中

### 定制手机外观

编辑世界书 `01_基本设置.txt`：

```ini
[基本设置]
默认边框色=#333333
默认背景色=#FFFFFF
默认气泡色_自己=#DCF8C6
默认气泡色_他人=#FFFFFF
默认文字色=#000000
```

### 添加自定义表情

编辑世界书 `02_表情包列表.txt`：

```
表情名=表情URL
开心=https://example.com/emoji_happy.png
```

### 配置角色头像

编辑世界书 `04_角色头像.txt`：

```
小明=https://example.com/avatar_xiaoming.jpg
小李=https://example.com/avatar_xiaoli.jpg
```

## ⚙️ 技术细节

### 框架和库

- **Vue 3** - 前端框架
- **Reactive** - 响应式状态管理
- **IndexedDB** - 本地存储
- **Regex** - 消息解析

### 数据流

```
AI输出文本
    ↓
脚本正则解析 (index.ts)
    ↓
消息解析 (message-parser.ts)
    ↓
创建Message对象
    ↓
添加到Chat/Post
    ↓
保存到酒馆变量 (phone-state.ts)
    ↓
Vue响应式更新
    ↓
UI自动渲染
```

### 状态管理

```
PhoneState (全局状态)
├── UI状态 → 保存到IndexedDB
│   ├── 位置 (position)
│   ├── 尺寸 (size)
│   ├── 显示状态 (isVisible)
│   └── 当前页面 (currentPage)
│
├── 主题配置 → 保存到酒馆变量
│   ├── 颜色 (borderColor等)
│   └── 字体 (textColor)
│
└── 数据 → 保存到酒馆变量
    ├── 聊天列表 (chats)
    └── 动态列表 (posts)
```

### 消息解析

```
正则表达式识别
    ↓
提取参数 (sender, receiver, content, timestamp)
    ↓
递归解析内容块 ([emoji-], [image-], [music-] 等)
    ↓
创建Message数组
    ↓
添加到Chat或Post
```

## 📝 消息格式详解

### 私聊消息

```
Phone.Private('发送者名','接收者名','消息内容','HH:MM');
```

**示例**：
```
Phone.Private('小李','小明','今天天气真好','18:30');
Phone.Private('小李','小明','来看看[image-公园风景]','18:31');
Phone.Private('小李','小明','[emoji-开心]','18:32');
```

### 动态消息

```
Phone.Home('发布者名','动态内容','HH:MM');
```

**示例**：
```
Phone.Home('小王','今天天气真好，去公园散步了','14:20');
Phone.Home('小王','[image-公园风景]','14:21');
```

### 特殊内容标记

| 标记 | 格式 | 说明 | 示例 |
|------|------|------|------|
| 表情 | `[emoji-名称]` | 表情包 | `[emoji-开心]` |
| 图片 | `[image-描述]` | 图片 | `[image-公园]` |
| 音乐 | `[music-歌名$歌手]` | 音乐分享 | `[music-晴天$周杰伦]` |
