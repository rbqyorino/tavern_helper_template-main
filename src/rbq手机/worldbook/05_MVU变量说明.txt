# MVU (MagVarUpdate) 变量系统说明
# 用于跟踪和更新消息楼层变量
#
# 如果您想在手机消息中保存复杂的状态信息（如：
# - 角色好感度变化
# - 故事线进度
# - 特殊事件标记
# - 动态统计数据
# ），可以使用MVU变量系统。
#
# ===== 基本概念 =====
#
# 1. stat_data: 核心数据
#    存储消息相关的状态数据，例如：
#    {
#      "favorability": 50,
#      "mood": "happy",
#      "story_progress": "chapter_1"
#    }
#
# 2. display_data: 显示数据
#    存储数据的可视化表示，例如：
#    {
#      "favorability_display": "❤️❤️❤️ (50/100)",
#      "mood_display": "😊 开心"
#    }
#
# 3. delta_data: 变化数据
#    记录数据的增减，用于显示变化趋势，例如：
#    {
#      "favorability_delta": "+10",
#      "mood_change": "sad → happy"
#    }
#
# ===== 初始化变量 =====
#
# 在世界书中使用以下格式初始化变量：
#
# [InitVar]
# {
#   "favorability": 0,
#   "mood": "neutral",
#   "interaction_count": 0
# }
#
# ===== 更新变量 =====
#
# 在AI生成的消息中使用以下格式更新变量：
#
# [stat favorability=50]
# [stat mood=happy]
# [stat interaction_count=1]
#
# 或者使用增量更新：
#
# [stat favorability+=10]
# [stat interaction_count+=1]
#
# ===== 显示变量 =====
#
# 在消息中显示变量的当前值：
#
# 当前好感度: {{favorability}} / 100
# 心情: {{mood}}
#
# ===== 本项目中的使用 =====
#
# RBQ手机模拟器目前主要采用更简单的数据存储方案
# （使用脚本变量而非MVU）。
#
# 如果您需要更复杂的状态跟踪功能，
# 可以启用MVU系统的支持。
