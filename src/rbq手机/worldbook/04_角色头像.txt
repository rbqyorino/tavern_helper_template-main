# 角色头像配置
# 为特定角色分配手机显示的头像
#
# 格式: 角色名=头像URL
#
# 使用方法：
# 在这里配置角色在手机界面中显示的头像
# 如果此处没有配置，将使用"随机头像"列表中的头像

# === 示例配置（请根据需要修改） ===
# 小明=https://example.com/avatar_xiaoming.jpg
# 小李=https://example.com/avatar_xiaoli.jpg
# 小王=https://example.com/avatar_xiaowang.jpg

# === 使用说明 ===
# 1. 替换"角色名"为实际的角色卡名称
# 2. 替换"头像URL"为实际的头像链接
# 3. URL应该指向可公开访问的图片
# 4. 推荐使用正方形图片（宽度和高度相等）
# 5. 图片大小建议不超过200KB

# === 默认头像服务 ===
# 如果您没有现成的头像，可以使用以下服务：
#
# DiceBear API (推荐)
# https://dicebear.com/
# 示例: https://api.dicebear.com/7.x/avataaars/svg?seed=角色名
#
# Gravatar
# https://gravatar.com/
# 示例: https://www.gravatar.com/avatar/用户邮箱md5值
#
# Robohash
# https://robohash.org/
# 示例: https://robohash.org/角色名.jpg
#
# UI Avatars
# https://ui-avatars.com/
# 示例: https://ui-avatars.com/api/?name=角色名&background=random
