# 手机应用模拟器 - AI消息格式规范

本文档定义了AI在生成聊天消息和动态内容时应使用的格式规范。这些格式将被脚本的消息解析器识别并转换为结构化数据。

---

## 消息格式规范总览

### 1. 私聊消息格式

私聊消息用于在聊天页面中显示两个用户之间的对话。

#### 基础格式

```
Phone.Private('发送者名','接收者名','消息内容','HH:MM');
```

#### 参数说明

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 发送者名 | string | 发送消息的人的名称 | '小李' |
| 接收者名 | string | 接收消息的人的名称 | '小明' |
| 消息内容 | string | 消息文本，支持特殊标记 | '今天天气真好[emoji-开心]' |
| HH:MM | string | 消息时间，24小时格式 | '18:30' |

#### 使用示例

```
Phone.Private('小李','小明','今天天气真好','18:30');
Phone.Private('小明','小李','是啊，要不要出去走走','18:31');
Phone.Private('小李','小明','好主意[emoji-开心]','18:32');
Phone.Private('小李','小明','[image-公园风景]','18:35');
```

---

### 2. 动态消息格式

动态消息用于在主页/朋友圈中显示用户发布的内容。

#### 基础格式

```
Phone.Home('发布者名','动态内容','HH:MM');
```

#### 参数说明

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 发布者名 | string | 发布内容的人的名称 | '小王' |
| 动态内容 | string | 动态文本内容 | '今天去公园散步' |
| HH:MM | string | 发布时间，24小时格式 | '14:20' |

#### 使用示例

```
Phone.Home('小王','今天天气真好，去公园散步了','14:20');
Phone.Home('小王','[image-公园风景]','14:21');
Phone.Home('小李','新的一天，新的开始[emoji-加油]','09:00');
```

## 特殊内容标记

在消息内容中可以使用以下标记来标识不同类型的内容。

### 1. 表情包标记

表情包用方括号标记，格式为 `[emoji-表情名称]`

```
[emoji-开心]
[emoji-伤心]
[emoji-生气]
[emoji-惊讶]
[emoji-加油]
```

#### 示例

```
Phone.Private('小李','小明','好的，我们一起努力[emoji-加油]','18:30');
Phone.Home('小王','太开心了[emoji-开心][emoji-开心]','14:20');
```

**说明**：
- 表情名称需要在世界书的"表情包列表"中定义
- 一条消息中可以包含多个表情
- 表情将以图片形式显示

### 2. 图片标记

图片用方括号标记，格式为 `[image-图片描述]`

```
[image-公园风景]
[image-美食照片]
[image-自拍]
```

#### 示例

```
Phone.Private('小李','小明','[image-公园风景]','18:35');
Phone.Home('小王','[image-美食照片]','14:25');
```

**说明**：
- 图片描述应简洁清晰
- 实际图片URL需要在运行时通过世界书的"表情包列表"或其他配置提供
- 图片将在消息中以卡片形式显示

### 3. 音乐标记（可选）

音乐用方括号标记，格式为 `[music-歌名$歌手]`

```
[music-晴天$周杰伦]
[music-起风了$买辣椒也用券]
```

#### 示例

```
Phone.Private('小李','小明','分享一首好听的歌[music-晴天$周杰伦]','18:40');
```

**说明**：
- 歌名和歌手用 `$` 分隔
- 音乐卡片将显示歌名和歌手信息
- 实际音乐链接可选配置

## 高级用法

### 混合内容消息

一条消息可以包含多个不同类型的内容块。

#### 示例

```
Phone.Private('小李','小明','今天天气真好[emoji-开心]，看我拍的照片[image-公园风景]','18:35');
Phone.Home('小王','新歌分享[music-起风了$买辣椒也用券]，很喜欢这个版本','15:30');
```

### 多条消息发送

同一个人的多条消息应该分别调用函数，每条消息会单独显示。

#### 示例

```
Phone.Private('小李','小明','你好','18:30');
Phone.Private('小李','小明','今天有空吗','18:31');
Phone.Private('小李','小明','我们一起去公园吧','18:32');
```

## 格式验证规则

### 必须满足的条件

1. **函数名必须正确**
   - 私聊使用 `Phone.Private()`
   - 动态使用 `Phone.Home()`
   - 末尾必须有分号 `;`

2. **参数必须用单引号括起**
   - 正确：`Phone.Private('小李','小明','消息','18:30');`
   - 错误：`Phone.Private("小李","小明","消息","18:30");`

3. **时间格式必须是 HH:MM**
   - 正确：`'18:30'`, `'09:00'`, `'23:59'`
   - 错误：`'6:30'`, `'18:30:00'`, `'18h30m'`

4. **消息内容中的特殊标记格式**
   - 表情：`[emoji-名称]`（中间用短横线 `-`）
   - 图片：`[image-描述]`（中间用短横线 `-`）
   - 音乐：`[music-歌名$歌手]`（歌名和歌手用 `$` 分隔）

## 常见错误示例

### ❌ 错误示例1：使用双引号

```
Phone.Private("小李","小明","消息","18:30");  // 错误！
```

**正确形式**：
```
Phone.Private('小李','小明','消息','18:30');  // 正确
```

### ❌ 错误示例2：时间格式错误

```
Phone.Private('小李','小明','消息','6:30');   // 错误：缺少前导零
Phone.Private('小李','小明','消息','18:30:00'); // 错误：包含秒
```

**正确形式**：
```
Phone.Private('小李','小明','消息','06:30');  // 正确
Phone.Private('小李','小明','消息','18:30');  // 正确
```

### ❌ 错误示例3：缺少分号

```
Phone.Private('小李','小明','消息','18:30')  // 错误：缺少末尾分号
```

**正确形式**：
```
Phone.Private('小李','小明','消息','18:30'); // 正确
```

### ❌ 错误示例4：特殊标记格式错误

```
[emoji开心]        // 错误：缺少短横线
[emoji_开心]       // 错误：应该是短横线而不是下划线
[image公园风景]    // 错误：缺少短横线
[music晴天-周杰伦] // 错误：应该用$而不是短横线
```

**正确形式**：
```
[emoji-开心]          // 正确
[image-公园风景]      // 正确
[music-晴天$周杰伦]   // 正确
```

## 设计建议

### 对于角色卡创建者

1. **保持消息的自然流畅**
   - 不要连续发送空消息
   - 消息内容应该符合角色性格

2. **合理使用特殊标记**
   - 不要过度使用表情
   - 图片和音乐适度使用，以体现内容的丰富性

3. **时间间隔的逻辑性**
   - 类似内容的消息时间间隔应该合理
   - 同一个人连续发送的消息之间间隔通常为几秒到几分钟

### 对于系统开发者

1. **向后兼容**
   - 如果引入新的标记类型，应该提供向后兼容的解析逻辑

2. **容错处理**
   - 对于格式不严格的输入，应该尽可能地进行纠正和理解
   - 使用日志记录格式错误，便于调试

3. **扩展性**
   - 预留接口，便于将来添加新的消息类型（如视频、语音等）
