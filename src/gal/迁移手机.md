# 手机界面功能移植到 GAL 前端界面 - 完整移植文档

## 📋 文档概述

本文档指导开发人员将 `src/手机界面`（脚本项目）的功能移植到 `src/gal`（前端界面项目）中，作为一个独立的可呼出功能模块。

---

## 🎯 移植目标

将手机界面功能集成到 GAL 前端界面，实现以下目标：
1. 在 GAL 游戏界面中可以呼出手机界面
2. 手机界面作为独立功能模块，可随时打开/关闭
3. 保留原有的聊天、联系人、动态等核心功能
4. 与 GAL 游戏界面无缝集成，共享状态管理
5. 数据通过 MVU 变量框架持久化

---

## 📊 技术架构对比

### 原手机界面（脚本项目）
- **运行环境**: 酒馆后台 iframe
- **挂载方式**: 通过 jQuery 手动挂载到父窗口 `document.body`
- **样式注入**: 使用 `teleport_style()` 将样式注入父窗口
- **显示方式**: 浮动窗口（position: fixed）
- **触发方式**: 脚本按钮"召唤手机"
- **数据存储**: MVU 聊天变量

### 目标 GAL 集成方案
- **运行环境**: 消息楼层 iframe（与 GAL 共享）
- **挂载方式**: Vue 组件，挂载到 iframe 内部
- **样式管理**: Vue scoped styles + SCSS
- **显示方式**: 模态覆盖层或侧边栏
- **触发方式**: GAL 底部菜单新增"手机"按钮
- **数据存储**: 继续使用 MVU 聊天变量（保持兼容性）

## 🔑 核心技术差异

### 1. jQuery 作用域差异

**原脚本方式**:
```typescript
// jQuery 直接作用于父窗口（酒馆页面）
const $tavernTextarea = $('#send_textarea'); // 访问酒馆输入框
```

**前端界面方式**:
```typescript
// jQuery 仅作用于 iframe 内部，需显式访问父窗口
const $tavernTextarea = (window.parent as any).$('#send_textarea');
```

### 2. 样式注入差异

**原脚本方式**:
```typescript
// 将 iframe 内样式复制到父窗口
export function teleport_style() {
  const styleContainer = document.createElement('div');
  document.querySelectorAll('head > style').forEach(style => {
    styleContainer.appendChild(style.cloneNode(true));
  });
  window.parent.document.head.appendChild(styleContainer);
}
```

**前端界面方式**:
```vue
<!-- 样式自动在 iframe 内生效，无需 teleport -->
<style lang="scss" scoped>
.phone-container {
  /* 样式代码 */
}
</style>
```

### 3. 组件生命周期差异

**原脚本方式**:
```typescript
// 手动管理组件挂载和卸载
$(() => {
  const $container = $('<div id="phone-app"></div>');
  (window.parent as any).$(window.parent.document.body).append($container);
  const app = createApp(Phone).mount($container[0]);

  $(window).on('pagehide', () => {
    app.unmount();
    $container.remove();
  });
});
```

**前端界面方式**:
```vue
<script setup>
// 使用 Vue 生命周期钩子
onMounted(() => {
  // 初始化逻辑
});

onUnmounted(() => {
  // 清理逻辑
});
</script>
```

#### 2.2 创建数据管理 Composable

**新建 `usePhoneData.ts`**:

```typescript
import { ref, onMounted, onUnmounted } from 'vue';
import { getScriptId, eventOn, eventOff } from '@types/function/event';

export interface Contact {
  id: string;
  name: string;
  avatar: string;
  lastMessage?: string;
  lastTime?: number;
  unread?: number;
}

export interface ChatMessage {
  id: string;
  contactId: string;
  content: string;
  time: number;
  isSelf: boolean;
}

export interface Moment {
  id: string;
  contactId: string;
  content: string;
  images?: string[];
  time: number;
  likes?: string[];
  comments?: Array<{ userId: string; content: string }>;
}

export interface PhoneData {
  contacts: Contact[];
  messages: ChatMessage[];
  moments: Moment[];
}

export function usePhoneData() {
  const phoneData = ref<PhoneData>({
    contacts: [],
    messages: [],
    moments: [],
  });

  const currentTime = ref(Date.now());
  let timeInterval: number;
  let updateHandler: () => void;

  async function loadPhoneData() {
    try {
      // 等待 MVU 初始化
      await waitGlobalInitialized('Mvu');

      // 从 MVU 变量读取数据
      const mvuData = Mvu.getMvuData({ type: 'chat' });
      const rawData = Mvu.getMvuVariable(mvuData, '手机数据', {
        default_value: {
          contacts: [],
          messages: [],
          moments: []
        }
      });

      phoneData.value = rawData as PhoneData;
    } catch (error) {
      console.error('加载手机数据失败:', error);
      toastr.error('加载手机数据失败', '错误');
    }
  }

  function savePhoneData() {
    try {
      const mvuData = Mvu.getMvuData({ type: 'chat' });
      Mvu.setMvuVariable(mvuData, '手机数据', phoneData.value);
      Mvu.replaceMvuData(mvuData);
    } catch (error) {
      console.error('保存手机数据失败:', error);
    }
  }

  // 与酒馆交互：填充消息到输入框
  function fillMessageToTavern(message: string) {
    try {
      const $textarea = (window.parent as any).$('#send_textarea');
      if ($textarea.length === 0) {
        toastr.warning('未找到酒馆输入框', '提示');
        return false;
      }

      const currentContent = $textarea.val()?.toString().trim() || '';
      const newContent = currentContent
        ? `${currentContent}\n${message}`
        : message;

      $textarea.val(newContent).trigger('input');
      $textarea.focus();
      return true;
    } catch (error) {
      console.error('填充消息失败:', error);
      return false;
    }
  }

  onMounted(() => {
    // 初始加载
    loadPhoneData();

    // 监听 MVU 变量变化
    updateHandler = () => {
      setTimeout(loadPhoneData, 100);
    };

    if (typeof Mvu !== 'undefined') {
      eventOn(Mvu.events.VARIABLE_UPDATE_ENDED, updateHandler);
      eventOn(Mvu.events.MESSAGE_VARIABLE_CHANGED, updateHandler);
    }

    // 更新时间
    timeInterval = window.setInterval(() => {
      currentTime.value = Date.now();
    }, 1000);
  });

  onUnmounted(() => {
    // 清理事件监听
    if (typeof Mvu !== 'undefined' && updateHandler) {
      eventOff(Mvu.events.VARIABLE_UPDATE_ENDED, updateHandler);
      eventOff(Mvu.events.MESSAGE_VARIABLE_CHANGED, updateHandler);
    }

    if (timeInterval) {
      clearInterval(timeInterval);
    }
  });

  return {
    phoneData,
    currentTime,
    loadPhoneData,
    savePhoneData,
    fillMessageToTavern,
  };
}
```

// 无需修改，直接复制即可
export function getTavernCharacterAvatar(character_name: string): string {
  const avatarImg = SillyTavern.getContext().characters
    ?.find((char: any) => char.name === character_name)
    ?.avatar;

  if (!avatarImg) return '';
  return SillyTavern.getContext().getThumbnailUrl('avatar', avatarImg);
}

export function processAvatar(avatarStr: string): string {
  if (!avatarStr) return '';

  const charMatch = avatarStr.match(/^char:(.+)$/);
  if (charMatch) {
    return getTavernCharacterAvatar(charMatch[1]);
  }

  return avatarStr;
}

#### 5.2 时间格式化

**新建 `src/gal/components/Phone/utils/time.ts`**:

```typescript
export function formatRelativeTime(timestamp: number, currentTime: number): string {
  const diff = currentTime - timestamp;
  const seconds = Math.floor(diff / 1000);
  const minutes = Math.floor(seconds / 60);
  const hours = Math.floor(minutes / 60);
  const days = Math.floor(hours / 24);

  if (seconds < 60) return '刚刚';
  if (minutes < 60) return `${minutes}分钟前`;
  if (hours < 24) return `${hours}小时前`;
  if (days === 1) return '昨天';
  if (days < 7) return `${days}天前`;

  const date = new Date(timestamp);
  return `${date.getMonth() + 1}月${date.getDate()}日`;
}

export function formatTime(timestamp: number): string {
  const date = new Date(timestamp);
  const hours = date.getHours().toString().padStart(2, '0');
  const minutes = date.getMinutes().toString().padStart(2, '0');
  return `${hours}:${minutes}`;
}
```

## ⚠️ 注意事项

### 1. 数据持久化

手机界面使用 MVU 变量存储数据，确保：
- 在使用 `Mvu` 前调用 `await waitGlobalInitialized('Mvu')`
- 数据变更后及时调用 `savePhoneData()`
- 监听 MVU 事件以同步其他来源的变更

### 2. 与酒馆交互

当需要访问父窗口（酒馆）的元素时：
```typescript
// ✅ 正确
const $element = (window.parent as any).$('#element-id');

// ❌ 错误（只会在 iframe 内查找）
const $element = $('#element-id');
```

### 3. 样式隔离

由于运行在 iframe 内，样式自动隔离：
- 使用 `scoped` 避免污染其他组件
- 全局样式（如字体）需在 `styles.scss` 中定义
- 不要使用 `vh`/`vw` 单位，改用百分比或 `aspect-ratio`

### 4. 生命周期

- 不要在 `<script>` 顶层执行异步操作
- 使用 `onMounted` 初始化数据
- 使用 `onUnmounted` 清理事件监听和定时器

### 5. 性能优化

- 使用 `v-show` 而非 `v-if` 切换手机显示（避免重复初始化）
- 对大列表使用虚拟滚动（可选）
- 图片使用懒加载
