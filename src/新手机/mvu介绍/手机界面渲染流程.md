# 咩咩手机界面 - 渲染流程详解

## 🎯 核心概念

咩咩手机是一个 **Vue3 应用**，通过以下步骤将 MVU 变量数据渲染成真实的手机UI：

```
MVU变量数据 (stat_data.手机数据)
    ↓
Vue组件（Phone.vue → ChatPage.vue）
    ↓
HTML/CSS 渲染
    ↓
用户看到的手机界面
```

---

## 📂 文件结构概览

```
src/咩咩手机界面/
├── index.ts              # 入口：初始化Vue App，挂载到酒馆网页
├── Phone.vue             # 主容器：手机框架、主页、聊天入口
├── ChatPage.vue          # 核心交互：消息、联系人、对话、动态
├── MomentsPage.vue       # 动态页面：显示动态列表
├── PublishMomentPage.vue # 发布动态：发布新动态
├── DraggableWrapper.vue  # 可拖拽包装：让手机可拖动
├── utils/avatar.ts       # 头像处理：解析char格式和URL转缩略图
└── 数据示例.json         # 数据格式示例
```

## 📱 Phone.vue - 手机外壳和主页

### 职责
- 渲染手机外观（物理框架、刘海、按钮）
- 显示主页内容
- 管理手机的显示/隐藏和拖动
- 加载并显示当前时间

### 核心代码片段

#### 1. 时间加载（重要！）

```typescript
const loadTimeFromTavern = async () => {
  await waitGlobalInitialized('Mvu');

  // 从MVU变量中读取当前时间
  const mvuData = Mvu.getMvuData({ type: 'chat' });
  const phoneData = Mvu.getMvuVariable(mvuData, '手机数据', { default_value: {} });

  if (phoneData?.当前时间) {
    // 将字符串时间"2025-01-23 18:00:00"转换为时间戳
    const timestamp = new Date(phoneData.当前时间).getTime();
    currentTime.value = timestamp;
  }
};
```

#### 2. 事件监听（实时更新）

```typescript
const setupTimeListener = () => {
  // 初始化时加载一次
  loadTimeFromTavern();

  // 监听MVU变量更新事件
  eventOn(Mvu.events.VARIABLE_UPDATE_ENDED, loadTimeFromTavern);

  // 监听酒馆消息生成完成事件
  eventOn(tavern_events.GENERATION_ENDED, () => {
    setTimeout(loadTimeFromTavern, 100); // 延迟确保变量已更新
  });
};
```

#### 3. 显示时间

```vue
<template>
  <!-- 状态栏时间 -->
  <span class="mimi-phone-time">{{ currentTimeText }}</span>

  <!-- 主页大时钟 -->
  <div class="mimi-home-clock">{{ currentTimeText }}</div>
  <div class="mimi-home-date">{{ currentDateText }}</div>
</template>

<script>
const currentTimeText = computed(() => {
  const date = new Date(currentTime.value);
  const hours = String(date.getHours()).padStart(2, '0');
  const minutes = String(date.getMinutes()).padStart(2, '0');
  return `${hours}:${minutes}`;
});

const currentDateText = computed(() => {
  const date = new Date(currentTime.value);
  const month = date.getMonth() + 1;
  const day = date.getDate();
  const weekdays = ['星期日', '星期一', ...];
  return `${month}月${day}日 · ${weekdays[date.getDay()]}`;
});
</script>
```

### 数据流：时间显示

```
stat_data.手机数据.当前时间 ("2025-01-23 18:00:00")
         ↓
loadTimeFromTavern() 读取
         ↓
currentTime.value (时间戳)
         ↓
currentTimeText / currentDateText 计算属性
         ↓
模板 {{ currentTimeText }} 显示
         ↓
用户看到：18:00 1月23日 星期四
```

## 💬 ChatPage.vue - 聊天页面（核心交互）

这是最复杂的组件，负责显示所有与联系人相关的数据。

### 职责
- 管理4个视图：消息列表、联系人列表、对话、动态
- 从MVU变量加载用户和联系人数据
- 显示聊天消息、联系人信息、空间动态
- 实现消息发送（填入酒馆输入框）
- 监听变化并实时更新UI

### 视图架构

```
ChatPage.vue
├── View 1: Messages（消息列表）
│   └─ 显示每个联系人的最后一条消息
│   └─ 数据来源：stat_data.手机数据.联系人[].聊天记录
│
├── View 2: Contacts（联系人列表）
│   └─ 显示所有联系人和签名
│   └─ 数据来源：stat_data.手机数据.联系人
│
├── View 3: Conversation（对话）
│   └─ 显示与某个联系人的完整对话
│   └─ 数据来源：stat_data.手机数据.联系人[contactName].聊天记录
│
└── View 4: Moments（动态）
    └─ 显示用户和联系人的所有动态
    └─ 数据来源：stat_data.手机数据.用户.空间动态 和
                  stat_data.手机数据.联系人[].空间动态
```

```typescript
function loadContactsData(contactsDataParam: Record<string, any>) {
  const formattedContacts: Record<string, ContactData> = {};

  Object.entries(contactsDataParam).forEach(([contactName, contactInfo]) => {
    // contactName 例如：甘雨、神里绫华
    // contactInfo 包含：昵称、签名、头像、聊天记录、空间动态

    formattedContacts[contactName] = {
      昵称: contactInfo.昵称,              // 例如："清心花茶"
      签名: contactInfo.签名,              // 例如："工作再忙,也要注意休息哦"
      头像: processAvatar(contactInfo.头像), // 处理头像URL
      聊天记录: contactInfo.聊天记录,      // 时间戳 → 消息对象的映射
      空间动态: contactInfo.空间动态,      // 动态数组
    };
  });

  contactsData.value = formattedContacts;
}
```

### 关键处理：时间格式化

```typescript
function formatTimestamp(timestamp: number, nowMs: number): string {
  const date = new Date(timestamp);
  const now = new Date(nowMs);
  const diff = nowMs - timestamp;

  // 5分钟内
  if (diff < 5 * 60 * 1000) return '刚刚';

  // 1小时内
  if (diff < 60 * 60 * 1000) {
    const minutes = Math.floor(diff / (60 * 1000));
    return `${minutes}分钟前`;
  }

  // 今天
  if (diff < 24 * 60 * 60 * 1000) {
    const hours = date.getHours().toString().padStart(2, '0');
    const minutes = date.getMinutes().toString().padStart(2, '0');
    return `${hours}:${minutes}`;
  }

  // 昨天、前天、三天前
  if (dayDiff === 1) return '昨天';
  if (dayDiff === 2) return '前天';
  if (dayDiff === 3) return '三天前';

  // 更早
  return `${month}/${day}`;
}
```

### 头像处理（avatar.ts）

```typescript
// 处理两种头像格式：
// 1. "char" 或 "char:xxx" → 解析为角色头像URL
// 2. "http://..." → URL直接使用

function loadContactsData(contactsDataParam) {
  Object.entries(contactsDataParam).forEach(([contactName, contactInfo]) => {
    const rawAvatar = contactInfo.头像; // 例如："char" 或 URL

    let processedAvatar = rawAvatar;
    if (rawAvatar === 'char' || rawAvatar.startsWith('char:')) {
      // 解析char格式为真实URL
      const resolvedAvatar = resolveAvatar(rawAvatar);
      // 转换为缩略图URL
      processedAvatar = convertAvatarToThumbnail(resolvedAvatar);
    } else if (rawAvatar) {
      // URL转缩略图
      processedAvatar = convertAvatarToThumbnail(rawAvatar);
    }

    // 使用处理后的头像
    formattedContacts[contactName].头像 = processedAvatar;
  });
}
```

## 🔗 事件监听链（实时更新）

ChatPage.vue 监听多个酒馆和MVU事件，确保UI与数据同步：

```typescript
const setupTavernDataListener = () => {
  // 初始化时加载一次
  loadTavernData();

  // MVU变量更新事件 - 最重要！
  eventOn(Mvu.events.VARIABLE_UPDATE_ENDED, loadTavernData);
  eventOn(Mvu.events.MESSAGE_VARIABLE_CHANGED, loadTavernData);

  // 酒馆消息事件
  eventOn(tavern_events.MESSAGE_UPDATED, () => setTimeout(loadTavernData, 200));
  eventOn(tavern_events.GENERATION_ENDED, () => setTimeout(loadTavernData, 300));
  eventOn(tavern_events.CHAT_CHANGED, loadTavernData);
  eventOn(tavern_events.MESSAGE_DELETED, () => setTimeout(loadTavernData, 200));
  eventOn(tavern_events.MESSAGE_SENT, () => setTimeout(loadTavernData, 500));
};
```

**事件流**：

```
AI生成消息 / 用户操作
         ↓
MVU框架更新 stat_data.手机数据
         ↓
触发 Mvu.events.VARIABLE_UPDATE_ENDED
         ↓
setupTavernDataListener 中的监听器捕获
         ↓
执行 loadTavernData()
         ↓
重新读取 MVU 变量
         ↓
更新 contactsData.value、userData.value
         ↓
Vue 计算属性自动重新计算
         ↓
模板绑定自动更新
         ↓
用户看到UI变化
```

## 🚀 性能优化

1. **计算属性缓存**：Vue会缓存计算结果，只在依赖变化时重新计算
2. **防抖数据加载**：使用 `isLoadingData` 标志防止重复加载
3. **延迟执行**：某些事件监听器添加延迟，确保变量已同步
4. **滚动防抖**：使用防抖对滚动操作进行优化，避免频繁滚动
